# Project 1: Linux EC2 Web Server using Terraform

Deploy a Linux EC2 web server on AWS using Terraform.

## Technologies
- AWS EC2, VPC, Subnets, Security Groups
- Terraform
- Linux, Bash, Apache/Nginx

## Deployment
```bash
terraform init
terraform validate
terraform plan
terraform apply
```

## Verification
Access the webpage using the EC2 public IP.
